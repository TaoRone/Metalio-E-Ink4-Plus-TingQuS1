# 听趣S1 社区版 v2.0.74-tq（2026-11-08）

> 基于官方 v2.0.74 固件的增强版。**刷机必须整刷**（分区表有调整，app-only 刷入会变砖循环）。

## 刷机

```bash
python -m esptool --chip esp32s31 --port COMx --baud 921600 write-flash --compress 0x0 firmware/metalio-e-ink4-2.0.74.bin
```

整刷会清空配置（WiFi / API Key 需重配）；书架缓存与封面在 SD 卡不受影响。

## 新功能

1. **KOReader kosync 进度同步**：首页「KOReader 同步」卡片。与 KOReader 设备（手机/电纸书）
   同一服务器+账号互通进度；支持文件内容/文件名两种书籍匹配（Reeden 导出的书请用文件名匹配，
   KOReader 端设置里也要切成按文件名）；开书自动拉、关书自动推，也可在阅读时长页手动上传/拉取；
   仅前进防回退。TXT 书按字节偏移近乎精确，EPUB 跨排版引擎为百分比近似（同章附近）。
2. **微信读书书架大改版**：3×3 封面网格（默认）/ 7 行信息列表双模式（顶栏切换，记忆选择）；
   封面缩略图 SD 缓存（二次秒开）；详情页大封面 + 阅读进度/时长/划线三行真实数据；
   行内「在线阅读」「AI 大纲」。
3. **M2 在线阅读（实验）**：微信扫码登录墨水屏账号（一次扫码长期有效）→ 拉取章节目录 →
   （正文接口受微信加密保护尚未打通，会明确提示）→ 合成 .ebook 进本地书库离线阅读（打通后自动可用）。
4. **AI 大纲**：官方 AI 精读接口，看书前快速了解全书概要+主题问答。需在扫码登录页
   「粘贴网页Cookie」（浏览器 weread.qq.com 登录后 F12 复制完整 Cookie 到局域网剪贴板槽 2）。
5. **局域网剪贴板**：网页三槽位，微信读书 API Key / 网页 Cookie 一键粘贴进设备键盘。

## 已知限制

- M2 在线阅读正文：微信对正文接口做了 JS 混淆+加密（死亡名单与实录在 docs/progress.md），
  社区有大神了解 weread 接口欢迎接力
- kosync EPUB 进度为百分比近似（两端排版不同），字级精度需 xpointer 解析（需求池）
- 官方 Agent API 对 Reeden 端产生的阅读记录可能无数据（微信侧限制）

## 技术底座（给开发者）

- ESP-IDF v6.1（mbedTLS 4.x）、ESP32-S31、16MB Flash / 16MB PSRAM
- 分区：ota_0/ota_1 各 0x530000（app 已 ~5.31MB，余量约 100KB）
- 构建：`idf.py -B ~/build/tingqu-s1 build`（工程路径含中文，构建目录必须纯 ASCII）
- 进展存档与踩雷实录：`docs/progress.md`
