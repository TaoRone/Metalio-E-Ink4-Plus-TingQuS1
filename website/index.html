官方电源管理

PowerPolicy 全套保留：待机浅睡、自动断网省电、网络宽限；联网应用按官方 PowerNeed 机制声明保网。

每日清单、百问 AI 默认隐藏（Kconfig 开关），代码完整保留，menuconfig 一键回开。

构建与刷机

  1. WSL2 + Ubuntu 24.04，安装 ESP-IDF v6.1（target esp32s31）
  2. git clone https://github.com/TaoRone/Metalio-E-Ink4-Plus-TingQuS1.git
  3. 构建目录需纯 ASCII 路径：idf.py -B ~/build/tingqu-s1 build（工程路径含非 ASCII 字符会触发 picolibc specs 路径 bug）
  4. BUILD_DIR=~/build/tingqu-s1 ESPTOOL_CHIP=esp32s31 bash merge_firmware.sh
  5. USB 刷入全量镜像，或 SD 卡放置固件卡刷。首次刷机前建议备份原厂 16MB 固件。

详细文档见 GitHub README 与 docs/。
