微信读书同步设置教程

全程约 3 分钟。Key 只存在你的设备本地，我们不会收集。

第 1 步：获取 API Key

  1. 电脑或手机浏览器打开 微信读书官网，扫码登录你的账号
  2. 点击右上角头像 → 设置（或「账号」页）
  3. 找到 「AI 助手」/「开放平台」/「API」 入口（2026 年 5 月起官方开放）
  4. 按页面提示用微信扫码授权，生成 API Key
  5. 复制 Key（形如 wrk-xxxxxxxx，共约 40 位），先存到电脑的记事本里

第 2 步：设备连上 WiFi

  1. 设备：设置 → 网络 → WiFi，选择你家网络并输入密码

第 3 步：一键把 Key 发给设备（推荐）

  1. 设备首页打开 「局域网剪贴板」，屏幕会显示一个网址，形如 http://192.168.x.x:8080
  2. 电脑浏览器打开该网址（详细图文见 剪贴板教程）
  3. 把 Key 粘贴到「粘贴位 1」，点 「设为微信读书Key」 —— 完成！

备选：在设备上手动输入

  1. 打开 「微信读书」应用，点底部 「API Key」
  2. 用屏幕键盘输入（SHIFT 切换大小写）
  3. 如果剪贴板里存过 Key，直接按 「USEKEY」 一键导入

第 4 步：看书架

回到「微信读书」应用，稍等几秒，你的书架就会同步下来。之后每次打开自动刷新（3 秒节流）。

常见问题
  • 同步失败：确认设备网络正常（屏幕顶部有 WiFi/4G 图标）；微信读书官网的 Key 是否被重置过
  • 有些书不显示进度：官方 API 对免费/试读书籍的进度字段可能为空
  • Key 安全：Key 相当于你的微信读书账号凭证，请勿分享给他人
