开发者文档

构建、刷机、参与开发。需要基础的 Linux 命令行经验。

环境要求

  • WSL2 + Ubuntu 24.04（或任意 Linux / macOS）
  • ESP-IDF v6.1（必须精确匹配，target esp32s31）
  • USB 数据线（注意避开仅充电线）

安装 ESP-IDF

git clone -b v6.1 --recursive https://github.com/espressif/esp-idf.git ~/esp/v6.1
cd ~/esp/v6.1 && ./install.sh esp32s31 && . ./export.sh

克隆与构建

git clone https://github.com/TaoRone/Metalio-E-Ink4-Plus-TingQuS1.git
cd Metalio-E-Ink4-Plus-TingQuS1

# 重要：构建目录必须是纯 ASCII 路径。
# 工程路径含中文/空格会触发 picolibc specs 路径 bug（gcc 读 specs 失败）。
idf.py -B ~/build/tingqu-s1 build

合并完整固件

BUILD_DIR=~/build/tingqu-s1 ESPTOOL_CHIP=esp32s31 bash merge_firmware.sh
# 产物：firmware/metalio-e-ink4-2.0.74.bin（约 16MB 全量镜像）

刷机

# USB 刷入（设备正常开机即可，esptool 会自动进下载模式）
idf.py -p /dev/ttyACM0 flash

# 或：把 firmware/metalio-e-ink4-2.0.74.bin 拷到 SD 卡根目录，
# 插卡重启，按屏幕提示确认卡刷

首次刷机前

  • 备份原厂固件：esptool read-flash 0x0 0x1000000 stock.bin，后悔药
  • WiFi 配置可在 SD 卡放 metalio/e-ink/settings/wificonfig.json 开机自动导入

功能开关（menuconfig）

配置项默认说明
TINGQU_HIDE_TASK_APPy隐藏每日清单（软裁剪，代码保留）
TINGQU_HIDE_ASSISTANT_APPy隐藏百问 AI 入口
MBEDTLS_SSL_RENEGOTIATION必须关闭esp-ml307 组件要求，否则 TLS 内存损坏

已知坑

  • 工程路径含中文 → 构建目录外置（如上）；这是 picolibc specs 的已知问题
  • 微信读书 HTTPS → 必须用 SDK esp_http_client；板载 HttpClient/EspSsl 栈对公网 TLS 有写入挂起问题（详见 git log ad93d19）
  • cJSON 大 JSON → 项目内已封装 CjsonPsramGuard，解析 ~100KB JSON 前切 PSRAM 钩子
  • 新加源码目录后需 idf.py reconfigure（CMake GLOB 不自动感知新文件）
