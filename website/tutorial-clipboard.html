局域网剪贴板使用教程

设备连上家里的 WiFi 后，电脑浏览器就能直接给设备"喂"文字：API Key、配置参数、备忘。全程 1 分钟。

第 1 步：打开剪贴板页面

  1. 确认设备已连 WiFi（设置 → 网络 → WiFi）
  2. 设备首页打开 「局域网剪贴板」 应用
  3. 屏幕上会显示一个网址，例如：http://192.168.31.21:8080

第 2 步：电脑访问

  1. 电脑连同一个路由器（有线/无线都行）
  2. 浏览器地址栏输入屏幕上的网址，回车
  3. 看到「听趣S1 · 局域网剪贴板」页面即成功

第 3 步：使用三个粘贴位

操作效果
粘贴内容 → 点「保存到粘贴位N」存入设备，长期有效（重启不丢）
点「设为微信读书Key」该位置内容立即作为微信读书 API Key 生效并触发同步
设备键盘上按 PASTE1/2/3把对应粘贴位内容插入当前输入
设备键盘上按 USEKEY自动扫描三个位置，首个合法 Key 直接采用

典型场景

  • 配置微信读书：电脑复制 Key → 粘贴位 1 → 点「设为微信读书Key」→ 完成
  • 存 WiFi 密码备忘：粘到粘贴位 2，设备随时可看（键盘 PASTE2 插入）
  • 预填 Reeden WebDAV 配置（Phase 3）：服务器地址/账号一次粘好，设备端一键带入
打不开页面？
  • 确认电脑和设备在同一个局域网（公司/校园网可能有隔离，换家里网络试）
  • 确认设备停留在「局域网剪贴板」页面（离开页面服务自动关闭）
  • 路由器开启了 AP 隔离的，关闭该功能
